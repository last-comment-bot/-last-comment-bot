# Telegram-бот «Последний комментарий побеждает»

## Что делает
- Отслеживает сообщения в группах и комментарии в привязанной группе обсуждений.
- После каждого сообщения участника сбрасывает таймер на 5 минут.
- Если новых сообщений нет 5 минут, объявляет последнего участника победителем.
- Управлять розыгрышем может только Telegram ID, прописанный в `bot.py` (сейчас это 8275854816).
- Хранит активные розыгрыши в SQLite, чтобы не терять их при перезапуске.

## Важно о комментариях канала
Telegram передаёт комментарии канала через привязанную группу обсуждений. Бот должен состоять в этой группе и иметь право читать сообщения.
Для команд в комментариях отвечай командой на исходный пост (например, `/startgiveaway` как ответ на пост в группе обсуждений). Для общего конкурса в чате отправляй `/startgiveaway` обычным сообщением в группе.

## Команды
- `/startgiveaway` — начать новый розыгрыш в текущем чате или ветке обсуждения.
- `/newgiveaway` — начать новый раунд (сбросить предыдущего участника).
- `/status` — посмотреть последнего участника и оставшееся время.
- `/stopgiveaway` — остановить конкурс без объявления победителя.

Команды доступны только владельцу с ID 8275854816.

## Запуск на компьютере или сервере
Нужен Python 3.10 или новее.

1. Распакуй архив.
2. Установи зависимости:
   `pip install -r requirements.txt`
3. Скопируй `.env.example` в `.env`.
4. В `.env` вставь токен от @BotFather в `BOT_TOKEN=...`.
5. Запусти:
   `python bot.py`

Не отправляй токен никому и не публикуй файл `.env`.
Для работы 24/7 программу нужно разместить на постоянно работающем сервере/VPS или другом хостинге с поддержкой Python.

## Замечания
- Бот не может читать сообщения в произвольных чужих чатах или каналах, куда его не добавили.
- В группе Privacy Mode должен быть выключен; после изменения настройки иногда требуется удалить бота из группы и добавить снова.
- В комментариях конкурса бот использует ветку обсуждения исходного поста. Начинай конкурс командой в ответ на соответствующий автоматически пересланный пост.
- Перед настоящим розыгрышем проверь механику в тестовой группе.
